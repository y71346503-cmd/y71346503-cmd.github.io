NEXUS

Privacy policy

Last updated: October 2, 2026

NEXUS is a personal desktop application used only by its author on their own Windows computer. This policy explains what happens to data NEXUS receives from Google.

Data NEXUS accesses

With the owner's consent, NEXUS reads and, when the owner asks, changes data in the owner's Google account: Gmail messages and labels, Google Calendar events, Google Tasks, Google Drive file names, Google Classroom courses, assignments, announcements and teachers, and Google Contacts (names, e-mail addresses, phone numbers and birthdays).

How the data is used

The data is used only to show and manage it inside NEXUS for the owner: to list mail and tasks, plan the day, remind about events and birthdays, and keep NEXUS in sync with Google. Messages are sent and items are deleted in Google only after the owner explicitly confirms each action.

Where the data is stored

Everything is stored locally on the owner's computer, in a database file inside the application folder. Access tokens are kept in the Windows Credential Manager. NEXUS has no server: no data is sent to the developer or to anyone else.

AI processing

When the owner asks for a summary or a reply draft, the text of the selected message may be processed by an AI model: a local model running on the same computer (Ollama), or Anthropic Claude through the owner's own Claude Code account. Nothing is used to train models by NEXUS, and no data is sold or used for advertising.

Google API Services User Data Policy

NEXUS's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

The owner can disconnect a Google account in NEXUS settings, which deletes its token, revoke access at myaccount.google.com/permissions, and delete all stored data by deleting the application's data folder.

Contact
